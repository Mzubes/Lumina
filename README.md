# Private Markets OS MVP

AI-native operational bridge for private-market allocators.

The MVP connects **pre-trade manager diligence** with **post-trade private-market operations** through a shared, evidence-backed data model.

## What we are proving

> Can an allocator move from a messy GP document package to an investment decision, then from an investment decision to validated portfolio operations, without repeatedly re-keying the same information?

## Current scope

- Pre-trade GP/fund document ingestion
- AI-assisted diligence and structured extraction
- Evidence-backed investment memo generation
- Allocation/commitment state
- Post-trade capital-call / statement ingestion
- Deterministic validation and reconciliation
- Exception workflow
- Portfolio state
- Downstream export abstraction

See `docs/PRIVATE_MARKETS_OS_MVP.md`, `docs/ARCHITECTURE.md`, and `docs/ROADMAP.md`.

## Development

The initial implementation will be added incrementally as a vertical slice. Production credentials and investor documents must never be committed to this repository.
